Pre-Departure Load Safety Gate

Ворота безопасности загрузки

Одно фото фуры на выезде → решение о выпуске за 1–2 секунды.
Измеряемо. С талоном. С журналом смены.

Computer Vision · демо: loadsafety.astrotms.com
Проблема

Неправильная загрузка стоит дорого

  • Несимметричная / перегруженная укладка → смещение груза, опрокидывания, потеря груза, штрафы, ДТП.
  • Сейчас контроль — на глаз (субъективно, нигде не фиксируется) или никак.
  • Нет объективной отсечки на воротах и нет истории для разбора.

Пользователь: выпускающий / диспетчер / весовщик на выезде с территории.

Решение

Фото → талон GO / NO-GO

  • Водитель на воротах делает 1 фото.
  • Система выдаёт ВЫПУСК РАЗРЕШЁН / ПРОВЕРИТЬ / ВЫЕЗД ЗАПРЕЩЁН с измеренным креном.
  • Каждый осмотр → журнал смены + счётчики. Рабочий инструмент, а не демо алгоритма.
Демо

Живьём с телефона жюри

loadsafety.astrotms.com

  • Дашборд смены: осмотров / выпущено / задержано.
  • Фото нормы → GO. Фото перекоса → NO-GO, красная линия наклона.
  • Осмотр тут же падает в журнал с номером талона.
Технология — это система, не промпт

YOLO × 2 + геометрия + правила

  • YOLOv8n → детекция грузовика; YOLO-World → тугой бокс кузова (zero-shot).
  • OpenCV-геометрия крена (Canny + HoughLinesP, усреднение борта гасит перспективу) → пороги GO/WARN/NO-GO.
  • Плохой кадр → честное «не оценить», а не ложный вердикт. LLM в ядре нет.

Пилот и дальше

3 месяца до рабочей отсечки

  • Мес 1: камера на воротах, сбор своего датасета (их траки, их ракурс).
  • Мес 2: дообучение детектора, калибровка порогов под их груз/ПДД.
  • Мес 3: модули свес/высота (сейчас roadmap), интеграция журнала с весовой/TMS.

Vision: «AI-копилот ворот автопарка» — загрузка, крепление, высота, негабарит, видео-поток.
