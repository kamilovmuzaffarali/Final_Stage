# 🚚 Pre-Departure Load Safety Gate

AI-ворота контроля загрузки грузовика. По **одному фото** фуры перед выездом
система выдаёт **GO / WARN / NO-GO** с объяснением:

- **крен кузова** (дисбаланс загрузки → риск опрокидывания),
- **свес груза** за габарит (боковой/задний),
- **крепление/дверь** (незакреплённый груз, открытая дверь).

Пользователь: логистика / автопарк / весовая. Ценность: меньше опрокидываний,
потерь груза и штрафов. Партнёрский контур: коммерческий транспорт (Toyota/BYD).

## Это система, а не «один промпт»
Пайплайн из трёх ступеней (`src/pipeline.py`):
1. **Детекция** грузовика/груза — YOLOv8 (дообучается на своём датасете, `train/`).
2. **Геометрия крена** — OpenCV: Canny + HoughLinesP → угол доминантных линий кузова.
3. **Решающий слой** — пороги → GO/WARN/NO-GO + человекочитаемое объяснение.

LLM в ядре не используется. Инференс — CPU (YOLOv8n), без GPU в проде.

## Запуск
```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
# открыть http://localhost:8000  — загрузить фото грузовика
```
Своя дообученная модель: положить веса и задать `MODEL_PATH=путь/к/best.pt`.
Без неё пайплайн работает на предобученном YOLOv8n (класс `truck` из COCO) — honest MVP.

## Обучение своей модели
```bash
python train/train.py   # данные: data/, схема классов: train/data.yaml
```

## Структура
```
app/        FastAPI-сервис (веб-аплоад → решение + аннотация)
src/        ядро CV-пайплайна (детекция + геометрия + решение)
web/        простая веб-страница загрузки (тест с телефона/ноута)
train/      дообучение YOLO + схема датасета
data/       датасет (images/labels) — собирается командой
docs/        питч и источники данных/лицензии
```
