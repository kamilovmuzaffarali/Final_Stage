# PlateVision — UZ License Plate Recognition (CV track)

Локализованное распознавание **узбекских автономеров** по фото: детект номера →
выравнивание перспективы → наш OCR (обучен на нашем датасете) → проверка формата
UZ → решение/гейт «не читаю». Бизнес-инструмент для сервиса/дилера/парковки
(идентификация авто по номеру), не система штрафов.

Ветка проекта: `platevision` (main — другой проект). Режим и бизнес-кейс — в `docs/`.

## Данные (источники задекларированы)
- **Синтетика:** генерим сами, `data/gen_synth.py` (формат UZ + аугментации).
- **Реальные фото:** публичные объявления OLX.uz, раздел «Легковые авто»
  (`data/harvest_olx.py`); манифест с URL каждого фото — `data/olx_raw/sources.csv`.
- Персональные данные не используются; лица/люди в кадр не берём.

## Как запустить (кратко)
```
pip install -r requirements.txt
python data/gen_synth.py --n 6000 --out data/synth      # синтетический трейн
python data/harvest_olx.py --n 400 --out data/olx_raw   # реальные фото (валидация/демо)
# обучение OCR и пайплайн — см. src/ (train/eval/serve)
uvicorn app.main:app --host 0.0.0.0 --port 8860          # веб-демо
```

Деплой публичный (тест с телефона), метрики на своём тест-сете, failure-cases —
в `docs/METRICS.md` (по мере готовности).
