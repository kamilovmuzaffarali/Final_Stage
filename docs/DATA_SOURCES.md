# Источники данных и лицензии

Личные данные (лица, номера людей) НЕ используются.

## Собственный сбор (основной датасет)
- Фото/видео реальных грузовиков на улице и логистических дворах — сняты командой
  в дни финала. Лицензия: собственная (CC-BY для сабмита).
- «Крен / свес / незакреплённый груз»: масштабные/игрушечные модели грузовика с
  грузами на наклоняемой платформе — сняты командой. Собственная лицензия.
- Синтетика (при наличии): 3D-модель грузовика (Blender), рендеры под разными
  углами крена. Метод генерации задекларирован, лицензия на 3D-ассет указывается.

## Предобученные веса
- YOLOv8n (Ultralytics), лицензия AGPL-3.0 — используется как стартовые веса и
  как fallback-детектор (класс `truck` из COCO). Атрибуция: Ultralytics.

## Публичные датасеты (опционально, для «нормы»)
- Открытые изображения грузовиков из датасетов с указанием лицензии
  (напр. COCO — CC-BY 4.0; Open Images — CC-BY 4.0). Конкретные файлы и лицензии
  перечисляются здесь по мере добавления.

> Каждый добавленный источник фиксируем строкой: что, откуда, лицензия.
