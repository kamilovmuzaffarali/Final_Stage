# Источники данных и лицензии — PlateVision

Весь датасет собран/сгенерирован нами. Персональные данные не используются;
людей/лиц в кадр не берём.

## 1. Синтетические номера (обучение OCR)
- **Что:** изображения узбекских автономеров по формату UZ с ground-truth текстом.
- **Как:** генерируем сами — `data/gen_synth.py` (рендер формата UZ: регион + группа
  + флаг/UZ, вариации тона; аугментации — при обучении: перспектива, блюр, шум,
  свет, JPEG-деградация).
- **Лицензия:** наша, создано для проекта. Объём: ~7000 изображений.

## 2. Реальные фото авто (детекция + валидация)
- **Что:** публичные объявления купли-продажи авто с **OLX.uz**, раздел
  «Легковые автомобили» (category_id=108).
- **Как:** `data/harvest_olx.py` через публичный API OLX; манифест с URL каждого
  изображения и id объявления — `data/olx_raw/sources.csv`.
- **Использование:** фоны для композитного детекционного датасета + реальная
  валидация распознавания. Фото публичные (объявления о продаже).

## 3. Композитный детекционный датасет (обучение детектора)
- **Что:** реальные фото авто (п.2) + вклеенные синтетические номера (п.1) со
  случайным масштабом/позицией/перспективой; bbox известен точно → авторазметка.
- **Как:** `data/make_detect.py`. Полностью производное от наших данных.

## Предобученные веса (задекларировано)
- `yolov8n.pt` — Ultralytics YOLOv8n (COCO), лицензия AGPL-3.0 — как бэкбон для
  дообучения нашего детектора номера на наших композитах.
- CRNN (распознаватель) обучен нами с нуля на нашем синтетическом датасете.
