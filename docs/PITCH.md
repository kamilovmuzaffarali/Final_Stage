# Защита — 7 минут (раскадровка под веса критериев)

Режим на первом слайде: **Partner product** — модуль для службы выпуска транспорта
автопарка/логистики (меняет процесс «предрейсовый осмотр загрузки»). (Можно Startup.)

## 1 мин — Проблема и пользователь
- Неправильная загрузка → опрокидывания, потеря груза, штрафы, ДТП.
- Сейчас проверяют глазами или никак. Пользователь: выпускающий на воротах/весовой.
- Цифра боли: стоимость одного опрокидывания/потери груза, частота (вставить источник).

## 2 мин — Живое демо (деплой)
- Открыть задеплоенный сайт с телефона жюри.
- Загрузить фото фуры (их вход) → GO/WARN/NO-GO + крен + аннотация за ~1–2 с.
- Показать 2 кейса: норма (GO) и перекос (NO-GO).

## 2 мин — Технология (это система, не промпт)
- Архитектура: YOLO (детекция) → OpenCV-геометрия (крен) → решающий слой.
- Свой датасет + тест-сет: сколько фото, как собирали, лицензии.
- Метрики: mAP50 детектора, MAE угла крена (°), P/R классов риска, FPS, $/инференс.
- Failure-cases: ночь, сильный ракурс, частичный кадр, блики — честно.
- Где крутится: CPU-сервер/edge; стоимость за камеру/проверку.

## 1.5 мин — Бюджет и ROI
- Стоимость пилота (3 мес): люди, инфра (1 CPU-инстанс), сбор данных, лицензии.
- Юнит-экономика: $/проверка; экономия на 1 предотвращённом инциденте.
- Payback: при N проверок/день и X% предотвращённых инцидентов — срок окупаемости.

## 0.5 мин — Next steps
- Дообучение на реальных данных автопарка, модули: свес/высота/крепление, видео-поток
  на воротах, интеграция с весовой/TMS. Roadmap: водитель + анти-угон (один «AI-копилот автопарка»).

## Anti-replication (почему не собрать за выходные)
- Не датасет из интернета, а **свой сбор + геометрический пайплайн + доменные пороги**.
- Преимущество: данные (локальные/модельные) + метод оценки крена + интеграция в процесс.

## Q&A — заготовки
- «Это же просто YOLO?» → YOLO только детектит; решение даёт геометрия + правила; метрики на своём тест-сете.
- «Точность крена?» → MAE X° на тест-сете; калибровка по референсу кузова; ограничения заявлены.
- «Про LLM» → в ядре LLM нет; код писали с ассистентом, логику объясняем сами.
