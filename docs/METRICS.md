# Метрики (честные, на своём тест-сете)

## Точность измерения крена кузова
Контролируемый тест: 20 реальных фото грузовиков (Wikimedia Commons, свободные
лицензии) × 7 известных углов поворота (-10…+10°) = 131 замер. Ground-truth — угол поворота.

- **TILT MAE = 2.40°** (медиана 0.95°).
- По углам: 0° → 0.00°; ±3° → ~2.3–2.9°; ±6° → ~2.4–2.9°; ±10° → 2.6–3.8°.
- **Вывод:** ошибка (2.4°) существенно меньше порогов решения
  (WARN ≥ 4°, NO-GO ≥ 7°) → классификация GO/WARN/NO-GO устойчива.

Воспроизвести: `python src/eval_tilt.py data/images/public 20`

## Скорость / стоимость
- Полный пайплайн (YOLOv8n + геометрия) на CPU ноутбука: **~29 мс/кадр ≈ 34 FPS**.
- Инференс полностью CPU, без GPU в проде. При ~$0.01/CPU-час эконом-инстанса и
  34 кадр/с одна проверка ≈ доли копейки; ботлнек — сеть/загрузка фото, а не модель.

## Известные failure-cases (честно)
- Ошибка крена растёт на больших углах (|10°| → ~3.8°).
- Полуприцеп с горизонтальным бортом: измеряется крен кузова, а не кабины.
- Ночь/сильные блики/частичный кадр/нестандартный ракурс — требуют дообучения на своих данных.
- Детекция свеса/крепления/высоты — включается после обучения этих классов (train/).
